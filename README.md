# Vor Blog

Blog personal.

- URL: <https://blog.voros.xyz>
- Stack: Astro, Svelte, Tailwind CSS
- Tema: Gruvbox dark-first con JetBrains Mono

## Estructura

```
.
├── public
│   └── assets
└── src
    ├── assets
    ├── components
    ├── content
    ├── layouts
    ├── lib
    ├── pages
    └── styles
```

## Desarrollo

```bash
cd blog
pnpm install
pnpm dev
```

Disponible en <http://localhost:4321>.

## Build

```bash
cd blog
pnpm build
pnpm preview
```
